# 🧬 CovidLassa: A Comparative Data Analysis of Lassa Fever and COVID-19

This project explores the similarities and differences between **Lassa Fever** and **COVID-19**, focusing on their impact in **California, USA**, and **Nigeria**. It uses real-world datasets and Python-based data analysis to visualize trends, identify patterns, and understand how these two infectious diseases spread and peaked between 2020 and 2024.

---

## 📍 Project Purpose

This analysis was developed to:
- Compare the death trajectories of two significant diseases: **COVID-19** (a global pandemic) and **Lassa Fever** (an endemic viral hemorrhagic fever).
- Examine how public health outcomes differ between a developed region (California) and a developing one (Nigeria).
- Apply data science techniques to real epidemiological datasets.
- Build practical experience in **data visualization**, **data wrangling**, and **public health communication**.

## 📊 Visual Outputs

This repo includes:
- A **7-day rolling average** of COVID-19 deaths in California
- A **side-by-side comparison** chart of COVID-19 and Lassa Fever deaths
- A **timeline visualization** showing peak deaths between 2020 and 2024

These plots help visualize the disparity in case reporting, mortality, and response between different regions and diseases.
